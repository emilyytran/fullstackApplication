Overview: My project is a game of TicTacToe with a 3x3 board, alternating turns, winner detection, and protection against continuing after a win.
How to run it: Copy and paste the files into CodeSandbox 
Your contribution: Instead of standard "X" and "O" players, there will be a "Dog" player and "Cat" player. I also changed the white background to a nice, sunny field 
What you learned: Learning how to import images into the code and displaying them. Another challenge was using css to properly size the images so that they would look good
References: I used the React tutorial and CodeSandbox. I also used this YouTube video to learn how to import and utilize images: https://www.youtube.com/watch?v=zF9SuGlLbkE
